## 目的与边界

帮助刚开始研究的学生或研究者从模糊方向、现实对象、已有条件和个人困惑出发，建立一个能够继续阅读、观察、比较和更新的个人研究课题项目。

不要要求用户先给出精确研究问题。把精确问题视为以下过程的产物：

```text
现实对象与困惑
→ 暂定研究方向
→ 候选问题
→ 初步阅读与观察
→ 问题比较
→ 当前优先问题
→ 持续修正
```

初始化的目标不是生成完整开题报告，也不是建立项目管理系统。目标是让研究者知道：

- 自己当前面对什么现象；
- 哪些认识只是直觉或假设；
- 有哪些值得比较的候选问题；
- 下一步为什么先寻找某类证据。

## 最小输入

允许用户只提供以下内容中的一部分：

- 想研究的物种、人群、组织、技术、地点或现实现象；
- 一个反复观察到却解释不清的现象；
- 一个实践问题或保护、管理、教育需求；
- 已有数据、场地、设备、样本、合作或方法条件；
- 个人兴趣、既有经验或初步判断；
- 时间、伦理、资源和能力限制；
- 已经接触过的少量材料。

不要因为缺少“题目”“变量”或“假设”而拒绝初始化。

信息不足时，每轮只提出 2–4 个真正会改变项目方向的问题。优先询问：

1. 你实际能够接触和持续观察的对象是什么？
2. 哪个现象让你觉得现有解释不够？
3. 你现在拥有哪些数据、场地、时间和方法条件？
4. 如果这个项目只能澄清一件事，你最希望澄清什么？

不要一次发出长问卷。允许学生用不完整、口语化的方式回答。

## 两阶段初始化

### 阶段一：初始化提案

根据学生提供的信息形成暂定结构，但不立即创建正式项目页面。

输出：

1. 现实起点；
2. 可用条件与约束；
3. 暂定研究方向；
4. 2–4 个候选问题；
5. 一个推荐的当前优先问题；
6. 已知、假设与未知；
7. 初始证据需求；
8. 第一轮学习循环；
9. 仍需学生决定的内容。

明确说明哪些内容来自学生，哪些是 Agent 的暂定解释。不要把推荐问题写成已经确定的课题。

### 阶段二：确认后建库

让学生确认或修改：

- 暂定研究方向；
- 当前优先问题；
- 保留的替代问题；
- 现实条件是否准确；
- 第一轮证据需求是否值得投入。

确认后再按照工作区规则创建实际页面。若学生不同意推荐问题，保留分歧和理由，不用说服性语言替其定题。

## 阶段一：形成初始化提案

### 现实起点

用具体对象和现象表达，不用宏大领域标签代替。例如：

```text
已有红外相机数据中，不同道路距离的兽类记录差异明显，
但尚不清楚差异来自真实活动变化还是检测条件。
```

优于：

```text
研究人类干扰对生物多样性的影响。
```

### 可用条件与约束

同时记录机会和限制：

- 能获得什么对象和数据；
- 数据怎样产生；
- 是否能继续补充；
- 时间与空间尺度；
- 已掌握和待学习的方法；
- 伦理、许可和隐私限制；
- 硕士阶段能够承担的工作量。

不要把“有数据”直接等同于“能回答问题”。

### 暂定研究方向

把方向写成“长期想理解的关系或机制”，而不只是方法和材料。

例如：

```text
理解人类活动怎样通过改变动物的空间使用和可检测行为，
影响红外相机监测结果及其保护解释。
```

### 候选问题

生成 2–4 个真正不同的问题，不要只是替换措辞。

候选问题可以分别关注：

- 现象是否存在；
- 可能机制；
- 发生条件；
- 测量或方法是否可靠；
- 结果如何影响现实决策。

保留问题之间的关系，说明哪些是前置问题、竞争路线或后续问题。

### 当前优先问题

推荐一个现在最值得先推进的问题，但使用“当前优先”而不是“最终题目”。

说明推荐依据：

- 它是否抓住真实现象；
- 是否能在现有条件下获得证据；
- 是否足以产生判断变化；
- 范围是否适合当前研究阶段；
- 它能否为其他候选问题提供基础。

同时说明它可能被什么新证据或现实限制替换。

### 已知、假设与未知

严格区分：

```text
已知：已有材料直接支持的事实。
假设：目前相信但尚未验证的解释。
未知：真正需要文献、观察、数据或方法检验的问题。
```

不要把常识、导师意见或 AI 推测写入“已知”。

### 初始证据需求

把每个重要未知改写为证据需求：

- 需要哪类事实；
- 需要哪种比较；
- 需要什么中间机制；
- 需要什么反方向结果；
- 需要怎样验证测量或方法；
- 文献能解决，还是必须依靠数据或现实观察。

## 候选问题比较

使用以下维度进行定性比较，不机械计算总分：

### 重要性

回答后会改变什么理论理解、研究设计或现实决策？

### 可回答性

问题需要的证据能否在当前阶段获得？

### 范围

是否小到能够推进，又大到值得回答？

### 证据匹配

现有或可获得的数据是否真正对应研究对象和推断目标？

### 认知增量

不同结果是否会改变当前认识，而不是只产生描述性数字？

### 前置价值

它是否能为其他候选问题建立概念、测量或事实基础？

不要只按“新颖性”排序。一个尚未解决的基础测量问题，可能比表面新颖的机制问题更值得先做。

## 阶段二：建立五个项目页面

遵守 [workspace-adaptation.md](workspace-adaptation.md) 的本地规则。以下是逻辑页面，不强制使用固定路径或文件名。

### 项目首页

连接其余页面，简要说明现实起点、暂定方向、当前优先问题、替代问题和更新时间。

### 研究方向与现实条件

保存研究对象、现实意义、可用数据与场地、能力基础、时间和伦理边界。

### 暂定问题地图

保存 2–4 个候选问题、它们之间的关系、当前优先顺序和选择理由。

### 当前认识、假设与未知

分别保存已知事实、暂定解释、竞争解释和无法判断的内容。后续的判断变化更新到这里或关联的问题页。

### 初始证据需求与第一轮学习

保存下一步需要寻找的证据类型、候选材料的特征、现实观察需求和停止条件。

不要额外创建任务表、人员表、投稿表或完整注册系统。

## 第一轮学习循环

不规定每周篇数或统一期限。根据当前问题依次寻找：

1. 能够界定核心概念和现象的锚点材料；
2. 对当前优先问题最有解释力的主要研究路线；
3. 最强竞争解释、相反结果或失败案例；
4. 能验证测量、数据和方法是否适配的材料；
5. 与本地对象、场地和现实条件最接近的证据。

每获得一项材料，使用 `triage` 决定 L0–L4 阅读深度，不默认精读。

第一轮学习的停止条件是：

- 候选问题之间的差异已经能够解释；
- 当前优先问题的选择有证据和现实条件依据；
- 核心概念、主要解释和最强反证已经出现；
- 下一步需要的是研究设计、数据核查或现实观察，而不是继续宽泛搜索。

## 从初始化转入日常运行

完成初始化后按以下循环工作：

```text
bootstrap
→ triage 新材料
→ read 核心材料
→ synthesize 形成当前认识
→ update 更新项目与问题页
→ select 生成下一项证据需求
→ 必要时回到 orient 重画问题地图
```

当新证据改变当前优先问题时，保留原问题和改变理由，不把历史重写成线性进步。

## 失败模式

- 让学生先写出精确题目才允许开始；
- 根据几个关键词直接生成完整开题报告；
- Agent 替学生确定唯一问题；
- 候选问题只是同一句话的不同措辞；
- 忽略数据生成、场地、时间和伦理条件；
- 只寻找支持最初兴趣的文献；
- 用固定阅读篇数代替证据需求；
- 把所有未知立即转换成任务；
- 初始化出十几个空白页面；
- 把知识项目扩展成进度、人员和行政管理系统。

## 完成标准

初始化完成不要求拥有最终题目。检查学生是否已经能够：

- 说明项目从哪个真实现象或现实条件出发；
- 区分研究方向、候选问题和当前优先问题；
- 说明为什么暂时先推进这个问题；
- 区分已知、假设与未知；
- 说出最需要的下一项证据及其理由；
- 保留至少一个替代问题或竞争解释；
- 知道在什么条件下应该修改当前优先问题；
- 使用建立的五个页面继续个人研究，而不依赖导师逐篇检查。
